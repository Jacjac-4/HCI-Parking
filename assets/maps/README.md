# Map attribution

Unmodified UNH Transportation map images, downloaded October 14, 2026 from links
on https://www.unh.edu/transportation/parking/permits/student for this educational
prototype. University of New Hampshire is the source of the map artwork. These
are reference maps, not live availability. The app serves the copies locally;
it does not navigate users to UNH's portal or fetch these images at runtime.

- commuter.jpg: https://www.unh.edu/transportation/sites/default/files/media/2026-06/Commuter_2627.jpg
- resident-core.jpg: https://www.unh.edu/transportation/sites/default/files/media/2026-06/Resident%20Core.JPG
- resident-west.jpg: https://www.unh.edu/transportation/sites/default/files/media/2026-06/Resident%20West_2627.jpg
- motorcycle-moped.jpg: https://www.unh.edu/transportation/sites/default/files/media/2026-06/MC_Moped_2627.jpg

Resident West and Non-Resident storage have the same three lots according to the
student-permit page; the UI explains why the Resident West image is shown for both.
The combined Resident Core map covers Gables, Woodside, Strafford, and Resident
East; the accompanying text specifies which subset the selected permit covers.
